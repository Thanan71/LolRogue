# Glossaire produit — français

La locale de lancement est `fr-FR`. Les noms propres de League of Legends, les noms
des champions, les runes et les raccourcis clavier restent inchangés.

| Concept interne | Terme affiché | Convention |
| --- | --- | --- |
| run | partie | Ne jamais afficher « run » au joueur. |
| encounter | rencontre | Employer le type précis si connu : combat, boutique, repos, événement. |
| HP / MP | PV / PM | Toujours en capitales dans l'interface. |
| gold | or | Minuscule après une valeur : `25 or`. |
| candies | bonbons | Ressource de maîtrise ; pluriel géré selon la valeur. |
| augment | amélioration | Ne pas confondre avec une amélioration permanente de champion. |
| enhancement | amélioration de champion | Progression permanente liée au champion. |
| elite | élite | Accent obligatoire. |
| boss | boss | Terme conservé, compris et stable dans le jeu. |
| mastery | maîtrise | Niveau de progression permanent d'un champion. |
| daily run | défi quotidien | Une tentative officielle par journée UTC. |

Les nombres et dates visibles passent par `Intl` avec la locale `fr-FR`.
